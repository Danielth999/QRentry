# QRentry

เว็บต้นแบบสำหรับประชาสัมพันธ์กิจกรรมนักศึกษาและจัดการการเข้าร่วมกิจกรรม มหาวิทยาลัยเทคโนโลยีราชมงคลตะวันออก

## เริ่มใช้งาน

เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือเปิดโฟลเดอร์นี้ด้วย Visual Studio Code แล้วใช้ส่วนขยาย Live Server

## บัญชีทดลอง

| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| ผู้ดูแลระบบ | `admin@rmutto.ac.th` | `admin` |
| เจ้าหน้าที่กิจกรรม | `staff@rmutto.ac.th` | `staff` |
| นักศึกษา | `student@rmutto.ac.th` | `student123` |

## ข้อจำกัดของต้นแบบ

- ใช้ข้อมูล JSON ตัวอย่างและ LocalStorage ในเบราว์เซอร์ ไม่มีฐานข้อมูลหรือเซิร์ฟเวอร์จัดเก็บข้อมูล
- การเปลี่ยนแปลงจะอยู่เฉพาะเบราว์เซอร์และอุปกรณ์ที่ใช้ และไม่ซิงก์กับผู้ใช้อื่น
- บัญชีและการเข้าสู่ระบบเป็นเพียงการจำลอง ข้อมูลบัญชีทดลองอยู่ในโค้ดหน้าเว็บซึ่งผู้เข้าชมสามารถตรวจดูได้
- QR Code และการเช็กชื่อจำลองการทำงาน ไม่ได้ตรวจจับ QR ด้วยกล้องจริง
- ไม่ควรใช้กับรหัสผ่านจริงหรือข้อมูลส่วนบุคคลของนักศึกษา
